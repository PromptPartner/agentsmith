THE WORK LOOP

A path from task to evidence.

AgentSmith supplies the structure; your project supplies the checks. The completion claim is tied to something a person can inspect.

  1. Project rules and a profile define boundaries and done.
  2. The agent works on one bounded task.
  3. Automated checks and a real invocation test the result.
  4. Evidence supports the completion claim.
  5. A handoff lets another session resume safely.
