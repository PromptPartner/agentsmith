# Support

## Get help

Search the [documentation](docs/README.md), [troubleshooting guide](docs/17-troubleshooting.md), and
[existing issues](https://github.com/PromptPartner/agentsmith/issues) first.

If you still need help, open a [GitHub issue](https://github.com/PromptPartner/agentsmith/issues/new/choose).
Choose the closest form, or open a blank support issue when none fits. Include:

- the AgentSmith version or commit;
- your operating system and agent client;
- whether this is a new or existing project;
- the command or workflow you followed;
- the expected and observed behavior; and
- sanitized output from `agentsmith status` or `agentsmith doctor`, when relevant.

Remove credentials, tokens, private source code, personal data, and confidential paths before posting.

## Bugs, ideas, and profiles

- Use the bug form for reproducible failures.
- Use the feature form for a new capability or workflow improvement.
- Use the profile form to propose a new work profile or a substantial profile change.

## Security and conduct

Do not use a public support issue for a suspected vulnerability. Follow the private reporting instructions in
[SECURITY.md](SECURITY.md). Report private conduct concerns through the channel in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
