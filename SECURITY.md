# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/PromptPartner/agentsmith/security/advisories/new).
This creates a private security advisory visible to the repository maintainers.

Do not disclose the vulnerability in a public issue, pull request, discussion, commit, or social post before
a coordinated fix is available. Include only the information needed to reproduce and assess the issue:

- the affected version or commit;
- the affected platform and configuration;
- reproduction steps or a minimal proof of concept;
- the expected and observed behavior;
- the likely impact; and
- any suggested mitigation.

Never include live credentials or personal data. Replace them with clearly marked test values.

## What to expect

Maintainers will acknowledge the report through the private advisory, investigate it, and coordinate next
steps there. Timing depends on severity, reproducibility, and the scope of the fix. Please keep details private
until the maintainers confirm that disclosure is appropriate.

## Supported versions

Security fixes target the latest published release and the current `master` branch. Older releases may require
an upgrade rather than a backport.

## Security questions

Use a regular [GitHub issue](https://github.com/PromptPartner/agentsmith/issues/new/choose) for general hardening
questions that do not reveal a vulnerability.
